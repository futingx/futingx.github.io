# Codex 项目使用教程

本文整理了 Codex 记忆系统配置、内置 Git 操作、GitHub + Gmail 联动自动化三大核心功能的使用方法，所有操作均可通过自然语言提示词完成。

> 💡 使用注意：请留意区分 **Codex 记忆系统** 与 **Claude Code** 的能力边界，二者配置与调用方式互不通用。





## 一、记忆系统：AGENTS.md 配置说明

配置文件分为「项目级」与「用户级」两种，作用范围不同，可按需选择配置：

| 配置类型 | 文件路径 | 生效范围 | 适用场景 |
| :------- | :------- | :------- | :------- |
| 项目级 | 项目根目录下的 `AGENTS.md` | 仅对当前项目生效 | 单个项目专属规则、工程化约定 |
| 用户级 | C 盘用户目录 `.codex` 文件夹内的 `AGENTS.md` | 整台机器全局生效 | 全局通用指令、个人偏好配置 |

## 二、内置 Git 操作流程

Codex 内置完整 Git 能力，无需手动输入命令，通过提示词即可完成常用版本控制操作。

### 1. 项目 Git 初始化
直接输入提示词，自动完成仓库初始化与无关文件过滤：
> 把当前项目初始化成一个 git 工程，注意排除不需要的文件

执行后会自动生成 `.gitignore` 规则并完成首次文件暂存。

### 2. 分叉会话代码回滚
针对历史会话的代码版本，可通过会话 ID 快速回滚：
1. 选中需要回滚的历史会话，点击「分叉会话」
2. 复制对应会话的 ID
3. 输入提示词：`代码回滚到当前 id`，即可完成版本回退

### 3. Git Worktree 多工作树开发
支持通过工作树实现多分支并行开发，无需频繁切换分支：
- 在项目内创建永久工作树，拆分不同功能独立开发
- 开发完成后，输入提示词：`合并到主分支`，自动完成代码合并
- 闲置工作树可直接删除，不影响主分支代码

## 三、GitHub 与 Gmail 联动自动化

支持手动执行与定时自动执行两种模式，可实现仓库信息拉取、邮件摘要自动发送。

### 1. 单次手动执行
输入以下提示词，即可一次性完成 GitHub 仓库查询 + 邮件摘要发送：

```text
请你调用/github来帮我查看一下我的github有哪些仓库。并且调用/gmail用我的账户发一封邮件，将仓库信息总结成摘要发送给我。
```

### 2. 定时自动化任务
将上述操作配置为定时任务，实现自动周期执行。输入提示词：
```text
请你把上述任务做成一个自动化任务，每周五下午五点发邮件给我。
```
配置生效后，系统会在每周五 17:00 自动拉取 GitHub 仓库信息、整理内容摘要，并通过 Gmail 发送到你的邮箱。
