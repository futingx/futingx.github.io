# codex项目教程

本文整理了 codex 记忆系统、内置 git 操作、github + gmail 联动自动化的使用方法，操作均通过提示词完成，使用时注意区分 codex 记忆系统与 claude code。





## Codex记忆系统 AGENTS.md 文件创建

配置文件分两种：项目级和用户级。项目级配置文件放在项目根目录的 AGENTS.md，仅对当前项目生效；用户级配置文件在 C 盘用户目录下的 `.codex` 文件夹里新建 AGENTS.md，对整台机器全局生效。

## Codex内置Git相关操作流程

1. 项目 git 初始化：输入提示词「把当前项目初始化成一个 git 工程，注意排除不需要的文件」即可完成仓库初始化和文件过滤。
2. 分叉会话代码回滚：选中需要回滚的历史会话，点击分叉会话，复制对应会话 id，输入提示词「代码回滚到当前 id」完成版本回退。
3. git worktree 多工作树开发：在项目内创建永久工作树拆分不同功能独立开发，完成后输入提示词「合并到主分支」完成代码合并，闲置工作树可以直接删除。

## GitHub与Gmail联动及自动化定时任务

单次手动执行：

```
请你调用/github来帮我查看一下我的github有哪些仓库。并且调用/gmail用我的账户发邮件一封邮件总结成摘要给我。
```

定时自动化配置：

```
请你把上述任务做成一个自动化任务，每周五下午五点发邮件给我。
```

配置后每周五 17 点会自动拉取仓库信息、整理邮箱摘要并发送邮件。
